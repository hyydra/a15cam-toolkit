# a15cam-toolkit

Remote camera control for a **rooted Samsung Galaxy A15 (SM-A156B, Android 15)** over ADB, plus a small burst stacker.

Samsung's HAL limits third-party Camera2 apps on this phone: no RAW, no extensions (Night/HDR), exposure capped at 0.1 s on the main camera, manual focus ignored. Samsung's own camera app is not bound by those limits (Pro mode: ISO 50-5000, shutter up to 10 s, manual focus; Night mode). `a15ui.py` drives that app by simulating touches found through `uiautomator`, so no screen coordinates are hard-coded.

| file | what |
|---|---|
| `a15ui.py` | Touch simulator over `uiautomator dump` + `input tap/swipe`: `dump`, `tap "name"`, `wait`, `xy`, `swipe`, `night`, `photo`, `map`, `pro --iso N --speed S --focus F`. Closed-loop slider setting for the Pro-mode wheels (reads the value from the slider's content-desc). |
| `a15cam.sh` | Helper for the headless Camera2 app below: wake, shoot, pull the JPEG. |
| `src/`, `AndroidManifest.xml`, `build.ps1` | `com.claude.a15cam`: a headless Camera2 activity (manual ISO / exposure / camera id, JPEG). Built without Gradle (aapt2 + javac + d8 + apksigner); `build.ps1` generates a local debug keystore (not committed). |
| `nightstack.py` | Burst stacker: ECC alignment, kappa-sigma-clipped mean, NLM denoise, tone curve. `python nightstack.py <dir> out.jpg [rot_ccw_deg]` |
| `MAP.md` | UI map of every Samsung camera mode, generated by `a15ui.py map` (One UI, 1080x2340). |

## Requirements
- Phone: rooted (the scripts use `su -c` to read `/sdcard/DCIM/Camera` and dump the UI), ADB reachable over TCP.
- Host: Python 3, `adb` on PATH. `nightstack.py` needs `numpy` and `opencv-python`.
- Set the device: `export A15_DEV=<phone-ip>:5555`.

## Usage
```sh
export A15_DEV=192.168.1.50:5555
python3 a15ui.py dump                              # what is on screen
python3 a15ui.py photo shot.jpg                    # normal photo
python3 a15ui.py night night.jpg                   # Night mode
python3 a15ui.py pro --iso 50 --speed 10 --out long.jpg     # 10 s at ISO 50 (about 1.5 min to set)
python3 a15ui.py pro --focus 0.5 --iso auto --speed auto    # manual focus, auto exposure
```
Photos land in `~/a15-media/`.

## Findings
- **Pro-mode wheels** fling: fast swipes overshoot. A closed loop works: read the value, swipe 140 px (halve on overshoot, 1200 ms drag), repeat. Swipe left = higher value.
- **Pro mode remembers its last settings**: after a 10 s shot, a normal photo burns out unless you pass `--iso auto --speed auto` (and `--focus auto`).
- **Manual focus scale is not "1.0 = infinity".** Measured with five shots through a window at a distant tree (Laplacian variance of the far region): 0.0 -> 3.8, 0.3 -> 4.3, **0.5 -> 339.5**, 0.7 -> 4.1, 1.0 -> 4.8. So 0.5 is sharp on distant scenery; the ends are blurry for far subjects. Only five samples and one scene: the real peak could be anywhere in 0.4-0.6, and the scale is probably non-linear.
- `uiautomator dump` takes about 1.4 s and is unreliable during animations; `tap` retries three times.
